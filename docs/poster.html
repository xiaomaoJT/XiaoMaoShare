XM 互传
局域网互传系统 · v1.4.0 说明

把同一 Wi-Fi 下的设备，
变成一块共享剪贴板

一个零依赖的 Node 服务，跑起来就是完整的互传面板。手机、电脑打开同一个地址，文字、图片、文件随手互传；图文混排成一条消息、Markdown、私聊、扫码、Telegram 远程同步都在这一个页面里，不用装 App，不用连外网。现在还有 图片画廊、已读回执、按人 / 按日筛选 和 彩色工具栏。

零依赖 Node ≥ 18 单文件服务端 单页前端 · 无框架 macOS / Windows / Linux
0依赖只用 Node 内置模块
4GB单文件上限，流式上传
1条文字 / 图片 / 文件任意合并
3套浅色 / 暗色 / 毛玻璃

界面

手机浏览器里就是这个样子

01 · 输入与消息流

一条输入区，图文随你排

文字、图片、附件可以任意交替，一次发成一条消息。工具条一键插表情、标题、代码、引用、列表，还能切到 Markdown 预览。

02 · 在线设备

谁在线，一眼看清

顶栏点开就是全部设备，主设备、本机各自标注，名字后面都带 IP，同 Wi-Fi 下不会认错人。

03 · 发送对象

发私聊，只有两台看得到

默认全局域网可见，选中某台设备就变成私聊。别人既收不到，也看不到这条消息的存在。

三套外观 + 四档字号

浅色、暗色、毛玻璃各取所需；正文字号还能单独调，只放大内容不动按钮，记在本机不影响别人。

AAAA 小 · 标准 · 大 · 特大

功能

九件事，都在一个页面里

合并发送

多张图片、图文混排、多类型文件，都收成一条消息发出，不再刷屏。

Markdown

标题、列表、表格、代码块都能写，消息卡片按排版渲染，写完可一键预览。

存为 .md 发出

写完点一下，内容打包成 .md 文件发送，图片内联进文件，对方下载就是可编辑文档。

私聊

只发给指定设备，别人看不到。发出去的消息带「仅对方可见」标记。

在线设备

主设备、本机、各设备 IP 一览，8 秒没心跳自动下线，不残留幽灵设备。

扫码访问

主设备一键生成局域网地址的二维码，别人扫一下就进来，不用手打 IP。

接入许可

陌生设备第一次访问要输密码（默认 XM），再由主设备点同意；之后长期有效。

三套外观

浅色、暗色、毛玻璃，一键切换，记在各自设备上，手机夜里不刺眼。

Telegram 远程

主设备配置 Bot，各端输密码解锁后，消息同时同步到手机，支持走代理。

本次更新v1.4.0

字号可调，看得清也看得舒服

图片画廊

一条消息里的多张图点开就是画廊：上一张 / 下一张、滚轮与双指缩放、下载、看原图，带「当前 / 总数」。

已读回执

复制、下载、看图都算读过；按授权设备去重、含发送者本人，主设备或提权设备还能展开看「谁已读」。

按人 / 按日筛选

发送人清单带头像与勾选态；日期用日历视图——只有真有内容的日期才可选，还能叠加分类标签。

彩色工具栏

两行排布，发送人紫、日期青、批量天蓝、清空红；宽屏图标 + 文字，窄屏自动收成图标。

字号四档

外观里切「小 / 标准 / 大 / 特大」，只放大正文与补充，按钮图标不动；带一条实时示例，选完立刻生效。

回到顶部

列表滚长了右下角浮出 ↑，点一下平滑回顶；配合批量选择、清空全部，整理起来更顺手。

消息可编辑

自己发的、带文字的消息随时改；修订历史直接标出这一版改了哪里（红色删除 / 绿色新增），旧版本不丢。

消息引用

任意消息点「引用」挂到输入区，下一条发出的消息带一张引用卡；点卡平滑跳回原消息并高亮。

追加补充

每条消息下都能补充，所有人可接龙；支持 Markdown、表情、图片与文件，补充人可自行删除。

身份与权限

一台主设备管权限，其他设备各自记账

01
主设备不靠 IP 认 用 localhost 或一次性令牌打开才算主设备，端口转发、虚拟网卡都不会把别人的电脑变成管理员。
02
授权按设备指纹记账 同一个 IP 上挂多台设备也互不覆盖；单独移除某台，其他设备照常在线。
03
权限可以分级 能整体关掉「其他设备发送」，也能分别禁止文字 / 图片 / 文件，主设备始终完整权限。
04
Token 不出主设备 Telegram Bot Token 单独存盘、权限 600，接口只回「配没配」，接收人和掩码只给主设备。
