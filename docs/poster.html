XM 互传
局域网互传系统 · v1.6.0 说明

把同一 Wi-Fi 下的设备，
变成一块共享剪贴板

一个零依赖的 Node 服务，跑起来就是完整的互传面板。手机、电脑打开同一个地址，文字、图片、文件随手互传；图文混排成一条消息、Markdown、私聊、扫码、Telegram 远程同步都在这一个页面里，不用装 App，不用连外网。现在还有 账户体系（可选登录，主控 / 管理员 / 成员三档角色）、图片画廊、已读回执、按人 / 按日筛选 和 彩色工具栏。

零依赖 Node ≥ 18 单文件服务端 单页前端 · 无框架 macOS / Windows / Linux 账户 + 三档角色 密码 scrypt 存派生值
0依赖只用 Node 内置模块
4GB单文件上限，流式上传
1条文字 / 图片 / 文件任意合并
3套浅色 / 暗色 / 毛玻璃

界面

手机浏览器里就是这个样子

01 · 输入与消息流

一条输入区，图文随你排

文字、图片、附件可以任意交替，一次发成一条消息。工具条一键插表情、标题、代码、引用、列表，还能切到 Markdown 预览。

02 · 在线设备

谁在线，一眼看清

顶栏点开就是全部设备，主设备、本机各自标注，名字后面都带 IP，同 Wi-Fi 下不会认错人。

03 · 发送对象

发私聊，只有两台看得到

默认全局域网可见，选中某台设备就变成私聊。别人既收不到，也看不到这条消息的存在。

04 · 账户与登录

想认同一个人，再登录账户

过完接入许可就能直接用，不登录也收发。想让内容记在「你」名下、想让手机和电脑算同一个人时，在顶栏登录：只填账户名 + 密码，页面上不列任何账户。

同一账户在手机、电脑同时登录就是同一个人：头像、消息归属、私聊可见范围都跟着账户走，换台设备登录还是同一张脸。

主控 · 全局 + 账户 管理员 · 审批 + 删人内容 成员 · 只发自己的

三套外观 + 四档字号

浅色、暗色、毛玻璃各取所需；正文字号还能单独调，只放大内容不动按钮，记在本机不影响别人。

功能

十五项功能，都在一个页面里

合并发送

多张图片、图文混排、多类型文件，都收成一条消息发出，不再刷屏。

Markdown

标题、列表、表格、代码块都能写，消息卡片按排版渲染，写完可一键预览。

存为 .md 发出

写完点一下，内容打包成 .md 文件发送，图片内联进文件，对方下载就是可编辑文档。

私聊

只发给指定设备，别人看不到。发出去的消息带「仅对方可见」标记。

在线设备

主设备、本机、各设备 IP 一览，8 秒没心跳自动下线，不残留幽灵设备。

扫码访问

主设备一键生成局域网地址的二维码，别人扫一下就进来，不用手打 IP。

接入许可

陌生设备第一次访问要输密码（默认 XM），再由主设备点同意；之后长期有效。

三套外观

浅色、暗色、毛玻璃，一键切换，记在各自设备上，手机夜里不刺眼。

Telegram 远程

主设备配置 Bot，各端输密码解锁后，消息同时同步到手机，支持走代理。

账户登录（可选）

不登录也能收发。想认同一个人时填「账户名 + 密码」——不列账户，登录页上看不到这里都有谁。

三档角色权限

主控管全局与账户；管理员能审批设备、删除他人内容；成员只发自己的。越权请求服务端直接 403。

账户管理面板

设置里新建 / 编辑 / 停用 / 删除账户，选角色、设密码。每行标出「角色 · 是否设了密码 · 几台设备在用」。

切换账户 / 退出

顶栏点自己的名字就能切换或退出，不用重输接入密码。主控设备本身就是主控，不提供退出。

资料跟着账户走

头像颜色与上传的头像挂在账户上，换台设备登录同一个人还是同一张脸；私聊也按人算。

密码不留明文

scrypt + 每账户独立盐存派生值，比较用恒定时间；同一 IP 连错 6 次锁 10 分钟。

身份与权限

设备能进就能用，账户把「同一个人」串起来

01
两层门，各管一段 接入密码管「这台设备能不能进这个房间」，过了就能收发。账户密码管「进来后你是哪个人」——可选，但只有它才能拿到管理能力。
02
主设备不靠 IP 认 用 localhost 或一次性令牌打开才算主设备，端口转发、虚拟网卡都不会把别人的电脑变成管理员。
03
角色定上限，设备再收紧 能不能发先看角色，再过一遍全局默认与该设备的独立开关——三层叠加，主控始终不受限。
04
Token 与密码都不外流 Telegram Bot Token 单独存盘、权限 600，接口只回「配没配」；账户密码只存派生值，明文不落盘也不下发。
