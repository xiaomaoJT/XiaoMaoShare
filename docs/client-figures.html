CAPABILITIES · 02

客户端能力地图

从「连进来」到「收得到」，按使用顺序分成五组。多数能力在网页端就有，桌面壳再叠加窗口级增强。

01 / ACCESS
⌁

接入与身份

进门认设备不认 IP，登录后认人
  • 扫码 / 输地址 / 接入历史一键回连
  • 接入密码 + 主机同意，隐藏密码免确认，账户密码也可直接进
  • 设备指纹 cid 授权，与 IP 无关
  • 可选账户登录，跨设备算同一个人；专属密码临时提权
  • 应用内切换 HTTPS，不需重新授权
02 / TRANSFER
⇅

收发与文件

一条消息里文字、图片、文件任意混排
  • 合并发送 · 图文混排，Markdown 直接排版
  • 一键存成 .md，图片内联、下载即可编辑
  • 拖拽 / 粘贴 / 并行上传，进度只增不减
  • >8MB 自动 8MB 分片续传，断一下只重发当前片
  • SHA-256 去重秒传、在线预览、ZIP 打包下载
03 / WORKSPACE
☷

浏览与协作

内容攒多了，列表本身也是个工具
  • 实时搜索 + 分类 / 发送人 / 日期筛选
  • 分页懒加载、断线自感知、切回前台自动补同步
  • 已读回执、编辑与修订历史、引用、追加补充
  • 指定可见（私聊），发出后还能改范围
  • 三套主题 / 四档字号 / 头像昵称，各自设备独立记
04 / OFFLINE & ALERT
◔

离线与提醒

主机不在了，也不至于对着空白页
  • HTTPS + Service Worker 缓存页面外壳
  • 主机停机后仍能刷新，靠 localStorage 快照还原内容
  • 桌面端系统通知由主进程统一发，连别人主机也提醒
  • 悬浮球：拖文件即发，跟随最近在用的窗口
05 / DESKTOP SHELL
▣

桌面窗口体验

只在使用 Electron 客户端时叠加
  • Windows 沉浸标题栏 + 自绘红绿灯，Win11 系统圆角
  • 关窗收进托盘，服务不停，手机照样能传
  • 吸顶输入条、沉浸式悬浮滚动条
  • 连接窗口与主机窗口地址不同、身份互不干扰
WHO DECIDES

能力由服务端说了算

页面只负责呈现。真正的闸门在主机：/api/list 每次回传 caps 与 limits，前端照着显示按钮。分片能力由 caps.chunked 协商，连到未升级的老主机自动回退整包上传。

网页端能力由主机下发，升级主机即全端生效 桌面端增强需更新客户端 App 权限 = 接入许可 × 账户角色 × 逐台设备开关
WHICH ONE · 03

端形态对照 · 我该用哪个

所有端打开的是同一份页面，差别只在「壳」：要不要装、能不能常驻、有没有系统级通知与悬浮球。

形态要不要装能当主机离线刷新新消息提醒专属优势
手机 / 电脑浏览器扫码或输地址，即开即用 不用 不能 HTTPS 下 页面通知需授权 零安装，临时用最省事
PWA · 添加到主屏幕iOS 推荐，Android 亦可用 不用 不能 HTTPS 下 页面通知需授权 全屏无地址栏，像原生 App
桌面版 · 连接窗口macOS / Windows 安装包 需安装 可切换 支持 系统通知 托盘常驻 / 悬浮球 / 圆角标题栏
Android APKWebView 薄壳 需安装 不能 支持 系统通知 地址预填 192.168.，文件上传友好
iOS · Safari 主屏幕WKWebView 壳为预留 不用 不能 支持 页面通知需授权 不用签名，加到主屏幕即可
「能当主机」是什么意思主机 = 在本机跑起服务、让别人连进来。浏览器与手机壳没有这份能力；桌面版用同一个 App 在「我的主机」和「连接别人」之间切换，两边窗口地址不同、互不干扰。
离线刷新与通知的两个前提离线刷新依赖 HTTPS（Service Worker 只在安全上下文注册）；系统通知只在桌面版由主进程统一投递，网页端走浏览器通知、需要授权。桌面端通知不看窗口在前台还是托盘，所有新消息都推。
页面由主机下发 · 升级主机即所有接入端生效 连别人主机时：双方都升级，桌面端通知才完整
